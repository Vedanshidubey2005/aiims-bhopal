# AIIMS Bhopal – Angular demo site
Requires Node 18.19+. Run: `npm install` then `npm start` (http://localhost:4200).
All content lives in `src/app/data.ts` (placeholders). Add real images to `src/assets/images/`
(official-1..5.jpg, gallery-1..12.jpg) and swap the placeholder blocks for <img> tags. Replace `src/assets/icons/aiims-logo.svg` with the official logo.
